# 🛡️ AI MailGuard - Fake Mail Detection

AI MailGuard is a Machine Learning based web application that detects whether an email is **Fake/Spam** or **Genuine**.

## 🚀 Features

- 📧 Detects fake/spam emails
- 🤖 Machine Learning based prediction
- 📝 Simple email text input
- ⚡ Fast prediction
- 🌐 Streamlit web interface
- 📊 Trained ML model with text vectorization

## 🛠️ Technologies Used

- Python
- Machine Learning
- Scikit-learn
- Pandas
- NumPy
- Joblib
- Streamlit
- Git & GitHub
- Git LFS

## 📂 Project Files

- `app.py` - Streamlit application
- `model.pkl` - Trained Machine Learning model
- `vectorizer.pkl` - Text vectorizer
- `combined_data.csv` - Dataset
- `README.md` - Project documentation
